## 10. Automation strategy

| Suite | Tests | When it runs |
|---|---:|---|
| Smoke (`@smoke`) | 20 | Every pull request and every deployment |
| Critical (`@critical`) | 21 | Merge to main; release gate |
| Regression (`@regression`) | 164 | Nightly, sharded |
| API (`@api`) | 116 | Every pull request (fast, no browser) |
| Bug Regression (`@bug`) | 11 | Nightly; proves fixed bugs stay fixed |

- **Framework pattern:** enterprise: page objects + components + fixtures + API clients + data factories.
- **Browsers:** chromium.
- **Traceability:** every test carries an id (`AT-xxxx`) that maps to a Zephyr test case, and failures file Jira bugs with the same id.
- **Quality gate:** zero critical failures; regression pass rate of 95% or higher.
