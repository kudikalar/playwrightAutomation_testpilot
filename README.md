## Install

```bash
npm ci
npx playwright install --with-deps
cp .env.example .env    # fill in values locally — never commit real secrets
```

## Run

```bash
npx playwright test                 # everything
npx playwright test --grep "@smoke"           # smoke
npx playwright test --grep "@critical"        # P0 journeys
npx playwright test --grep "@regression"      # full regression
npx playwright test --grep "@regression"   # one shard of four
npx playwright show-report reports/html
```

## Conventions

- Locator priority: role → accessible name → test id → label → stable text → stable CSS. No nth-child, absolute XPath or hashed classes.
- No hard waits: wait for a concrete signal (element state, API response, spinner hidden).
- Every test asserts something meaningful (UI + API + data where it matters).
- Tests are independent; data is created per test with unique values (see `utils/unique`).
- Test naming: `AT-####` + business scenario; files grouped by module.

## CI/CD

GitHub Actions: `.github/workflows/pr-validation.yml`, `.github/workflows/nightly-regression.yml`, `.github/workflows/release.yml`. Pull requests run lint → smoke → critical → quality gate; nightly runs the sharded regression across chromium.
